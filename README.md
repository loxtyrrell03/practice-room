# Practice Room

Twenty-eight days to the stage. A practice companion for one final recital:
today's blocks with built-in timers, piece security meters, a journal, and a
coach (Claude, via the Claude CLI in GitHub Actions) that knows the whole plan,
remembers what you tell it, and rebuilds tomorrow around how today actually went.

**This repo is only the app shell** — it contains no personal data. Everything
lives in the private companion repo `practice-room-data`, which the site accesses
with a token you paste once (browser-only storage).

Site: https://loxtyrrell03.github.io/practice-room/
Setup: see the README in `practice-room-data`.
